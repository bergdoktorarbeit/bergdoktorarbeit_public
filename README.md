
# Bergdoktorarbeit PHD
Here you'll find all the information about my doctoral dissertation at the University of Mainz, supported by ZDF Digital and using data from ZDF Media Research.
Find texts, data, scripts and more...

This is the public repository to the Bergdoktorarbeit project created for publication. This is a fork of the private [bergdoktorarbeit_github](https://github.com/bergdoktorarbeit/bergdoktorarbeit_github) repos.
